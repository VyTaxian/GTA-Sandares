------- Instructions:

You need to have the 1.0 US of GTA SA (if your game is from Steam/RGL, do a downgrade):
https://www.mixmods.com.br/2021/09/primeiros-passos-para-montar-um-gta-modificado/#Downgrade

Install the Essentials Pack:
https://www.mixmods.com.br/2019/06/sa-essentials-pack/

You can get more information on how to build a good stable GTA for mods here:
https://www.mixmods.com.br/2021/09/primeiros-passos-para-montar-um-gta-modificado/

Drag the mod folder to the root folder of your game.

You need at least "1024" (1 GB) of streaming memory configured for textures to load without bugs. To do this, install at least one of these (or all if you prefer): Open Limit Adjuster, Improved Streaming, MixSets.
https://www.mixmods.com.br/2022/10/open-limit-adjuster/
https://www.mixmods.com.br/2022/04/improved-streaming/
https://www.mixmods.com.br/2022/03/sa-mixsets/

If you use Proper Fixes (highly recommended) you need to download the specific version of Proper Fixes adapted to RoSA.
https://www.mixmods.com.br/2025/01/sa-proper-fixes/
and increase the priority of the "Proper Fixes" folder in modloader.ini:
https://www.mixmods.com.br/2015/07/tutorial-dicas-tudo-sobre-modloader-gta/#Priority

 == Compatibility:
 ModLoader considers .img files to always have priority below all other files.
 So, avoid installing original texture mods in modloader as they will remove HD textures.
 
 This mod already includes SA Optimized Map (optimized map textures). Remove it if you use it.

 == Support and help:
 If the readme file is not enough to help you with the installation, acess MixMods discord server and ask for help there.
